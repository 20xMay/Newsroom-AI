# ĐỒ ÁN GIỮA KỲ CSE122 - PHÁT TRIỂN ỨNG DỤNG WEB CƠ BẢN

- **Tên đề tài**: Hệ thống Tòa soạn Báo chí Thông minh (Newsroom AI)
- **Tên trang thực hiện**: Thư viện nguồn (Source Library)
- **Mục đích của trang**: Quản lý, xác minh và lưu trữ các nguồn tin cậy phục vụ cho phóng viên và biên tập viên.
- **Các chức năng chính**:
  - Tìm kiếm và lọc nguồn tin theo tên, URL, loại nguồn và trạng thái.
  - Thêm mới nguồn tin thông qua giao diện Modal tương tác.
  - Tự động cập nhật số liệu thống kê tổng số nguồn và trạng thái xác minh.
  - Chuyển đổi giao diện Sáng/Tối (Dark/Light mode).
- **Công nghệ sử dụng**: HTML5 Semantic, CSS3 (Grid, Flexbox, Media Queries), JavaScript ES6 (DOM Manipulation).
